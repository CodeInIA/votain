# World ID app store listing

The text for the Developer Portal, kept here because the portal has no export
and because a listing that exists only in a web form is a listing nobody can
review or restore.

**The MCP cannot write the localised content.** `configure_mini_app` takes one
set of descriptions with no language parameter, so step 3 of the portal wizard,
"Localised content", has to be filled in by hand. Everything else on this page
was set through the API: the languages, the countries, the logo, the meta tag
image and the three showcase images.

The languages are the ones the app actually ships, taken from
`frontend/src/i18n/locales`. The listing had previously offered Polish and
Turkish, which do not exist in the app, and omitted Arabic and Hindi, which do.

App name is `Votain` in every language, including the scripts that do not use
the Latin alphabet: it is a product name, not a word to translate.

## English (US)

> Votain is an end-to-end verifiable, anonymous voting platform. Organisations run elections where every voter can check their own ballot was counted, nobody can prove how they voted, and no authority can alter the result.
>
> Ballots are encrypted on your device and added up without ever being opened, so the count is public arithmetic anyone can re-run from the blockchain. Your identity is hidden inside the set of eligible voters by a zero-knowledge proof: the system can tell that you are entitled to vote and that you have not voted twice, without learning who you are.
>
> Votain is open source and was built as a Computer Engineering bachelor's thesis.
