# contracts/

Solidity 0.8.35 smart contracts for Votain: Semaphore V4, ERC-4337 paymaster, coercion-resistant `ElectionV4` with per-nullifier nonce.

```bash
npm install
npx hardhat test       # 5/5 passing
npx hardhat compile
```

See [`DEVELOPMENT.md`](DEVELOPMENT.md) for the full stack, contract reference, environment variables and known technical debt. See the [root README](../README.md) for project context.
