# contracts/

Solidity 0.8.37 smart contracts for Votain: elections whose ballots are exponential ElGamal ciphertexts proved by Groth16 circuits, an aggregate each election keeps itself, results published only with a proof that they decrypt it, and a gas tank and relay hub that reimburses whoever submits a voter's transaction. Voters are Semaphore V4 identities in a per-election tree; re-votes are hidden (see the root README).

NOT ERC-4337. A per-voter smart account published the link between an enrolment and the ballot that followed it, and hosted paymasters cannot fund gas per organizer. `ElectionPaymaster` says so in its own header.

```bash
npm install
npx hardhat test       # 222 passing, the E2E suite with real Groth16 proofs
npx hardhat compile
```

The E2E suite needs the circuits built first (`cd ../circuits && npm run build`).

## How the contracts fit together

```mermaid
flowchart TB
  organizer["Organizer wallet"]
  relayer["Issuer relayer / any sender"]
  registrar["Issuer registrar (owner)"]

  factory["ElectionFactory<br/>validates config, picks the smallest<br/>verifier pair that fits"]
  deployer["ElectionDeployer<br/>holds ElectionV4's creation code<br/>(too big for the factory)"]
  election["ElectionV4<br/>phases, members tree, ballots tree,<br/>ElGamal aggregate, tags, quorum"]
  paymaster["ElectionPaymaster<br/>organizer balances, per-election<br/>reserves, relayEnroll*/relayVote"]
  registry["PlatformRegistry<br/>platform members, status list,<br/>sealed vault, preferences"]
  domains["OrganizerDomains<br/>self-service domain claims"]

  subgraph verifiers["verifiers/ (generated by circuits/)"]
    bv["BallotVerifierS5, S9, ..."]
    tv["TallyVerifierS5, S9, ..."]
  end

  subgraph libs["libraries"]
    bjj["BabyJubJub.sol<br/>extended-coordinate adds"]
    pos["PoseidonT3 / T4, LeanIMT"]
  end

  organizer -- "createElection" --> factory
  factory -- "deploy" --> deployer
  deployer -- "new" --> election
  factory -- "reserveFromBalanceFor" --> paymaster
  organizer -- "deposit, reserve, withdraw" --> paymaster
  organizer -- "close early, void, publishResults" --> election
  relayer -- "relayEnroll*, relayVote" --> paymaster
  paymaster -- "enroll*, castVote, then reimburse" --> election
  registrar -- "registerMember, vault" --> registry
  election -- "verifiedMembers" --> registry
  election -- "verifyBallot" --> bv
  election -- "verifyTally" --> tv
  election --> bjj
  election --> pos
```
